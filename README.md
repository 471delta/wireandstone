# Wires & STONE — Private Atelier

Production-oriented Astro site for Wires & STONE. The project is intentionally image-free and uses editorial typography, SVG linework, CSS material treatment, and restrained GSAP choreography instead of 3D/WebGL.

## Requirements

- Node.js 22+
- npm 10+

## Install

```bash
npm install
```

## Develop

```bash
npm run dev
```

## Build

```bash
npm run build
```

The static output is written to `dist/`.

## Cloudflare Pages

Use the repository root as the project directory.

- Build command: `npm run build`
- Build output directory: `dist`

The project is configured as a static Astro site, so it does not require a server adapter for Cloudflare Pages.
